硬件分工更新：V3F 管完整键盘扫描与实时键盘引擎

V3F 输出语义化键盘事件，V5F 负责屏幕、配置、通信、资源和较高层产品状态。

V3F: Real-time Keyboard Engine
1

采样

ADC/DMA、MUX、滤波、校准、轴值计算。

2

触发

触发点、释放点、RT、DKS 阶段、SOCD/SpeedTap 判定。

3

键盘语义

层、Tap/Hold、Mod-Tap、组合键、基础宏调度。

4

事件上报

向 V5F 发送 HID-ready key events、状态变更和调试 telemetry。

V5F: Product/UI/Connectivity Host
A

输出与通信

USB/BLE/2.4G/HID、Local Core 同步、诊断。

B

屏幕系统

LVGL、页面模板、媒体资源、小组件、Agent 状态。

C

配置管理

Profile slot、资源包、版本、回滚、写入事务。

D

协调

把编译后的键盘运行配置下发给 V3F，并接收事件。
